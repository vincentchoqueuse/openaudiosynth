# Patch and song formats (version 2)

These formats are the reference implementation of the open format described in `spec/README.md`
(OID 0.3, JSON schemas in `spec/schemas/`). Check any file with `python3 tools/validate.py`.

Both are JSON, versioned, and validated against the DSP descriptor tables when loaded: unknown names,
unknown labels and missing fields are errors (the message lists the valid choices); out-of-range
values are clamped with a warning. Parameters, their roles, ranges and units: `docs/catalog.md`
(generated by `./build-host/host/synth_catalog`). Only version 2 is read.

## Patch — `patches/<name>.json`

```json
{
  "version": 2,
  "engine": "va",
  "name": "va_acid_bass",
  "description": "what it sounds like and why",
  "osc1": {"waveform": "saw"},
  "osc2": {"waveform": "pulse", "octave": -1, "pulse_width": 0.3, "level": 0.5},
  "filter": {"cutoff": 220, "resonance": 8, "keytrack": 0.3},
  "fx": {"delay": {"mix": 0.15, "time": 0.357}},
  "audition": { "notes": "C2! C2 C3 - Eb2 _ Bb1 C2", "bpm": 124, "step": 0.25, "gate": 0.6, "velocity": 100 }
}
```

- **Settings, grouped by module**: every key of the patch other than its own (`version`, `engine`, `name`,
  `description`, `kit`, `macros`, `audition`, `clip`) is a module, an object of settings, possibly nested
  (`"fx": {"delay": {...}}`, `"mseg1": {"point2": {"time": 0.5}}`). A leaf's path is a parameter's **role**
  (`filter.cutoff`, `fx.delay.mix`: the `role` column of `docs/catalog.md`), unique on every engine. Values in
  physical units (Hz, s, dB, cents, octaves, semitones…); enumerated parameters take a label (`"saw"`, `"lp"`)
  or its index. Omitted settings keep their default; an unknown one is an error that lists its module's.
  Besides the engine's modules, the shared ones: `master`, `fx` (chorus, delay, reverb, phaser, flanger, tape,
  rack), `output`, `tempo`, `tuning`, `part`, and the modulation (`macro1`.., `mlfo1`.., `mseg1`..,
  `route1`.., `vmseg`, `vlfo`, `vroute1`..).
- The library's files and the web page write the same layout (`tools/patchtree.py`, `web/ui/src/lib/patchjson.js`):
  2-space indent, a module on one line when it fits.
- `kit` (optional, the `sampler` engine): the sample kit the patch plays, by name (`"synth_analog"`): a
  directory of `NN_name.wav` files (NN: the MIDI note; pad 1 is the lowest note) found in `kits/NAME` (your own
  samples) or among the demo kits recorded from the drums engine at every build (`build-host/kits/NAME`,
  `host/kit_demo.c`). The patch's `padN_*` parameters set each pad (speed, start and end points, reverse,
  loop, decay, level, pan, cutoff, choke group).
- `macros` (optional): the sound's live controls, up to 8. Macro *k* of the array is the part's `macro`*k*
  (0..1: a knob, a CC through a controller map, the hub). Each moves its **targets** from a value (macro at 0) to
  another (macro at 1), in the target's own units and along its curve (a cutoff moves exponentially):

  ```json
  "macros": [
    { "name": "Brightness", "value": 0.35, "targets": [
        { "param": "filter.cutoff", "from": 400, "to": 4000 },
        { "param": "filter.envelope_amount", "from": 1.8, "to": 3.4 } ] },
    { "name": "Growl", "value": 0.2, "targets": [ { "param": "filter.drive", "from": 0.2, "to": 0.9 } ] }
  ]
  ```

  - `param` is the target's role. `value` (0..1) is where the macro starts; a target's value set in its module
    is replaced by its macro's.
  - Targets are engine parameters that move live (`realtime`), the master level or an effect (`fx.reverb.mix`,
    `fx.delay.feedback`, `fx.chorus.mix`...); 32 targets in all, in the part's `map1..map32` slots
    (`dsp/mod/partmod.h`).
  - Two macros on one parameter add their travel (also across parts for the effects); modulation routes add on
    top. When no macro holds an effect any more, it returns to the value last set (patch, CC 91/93/94).
  - `cc` (optional): the MIDI CC that turns the macro, 2..119 except 64 (0: none). By default macros 1..8 listen
    to CC 102..109, a free range: set a controller (or the hub) to send them, or give the CCs your knobs send.
- `audition` (optional): the phrase used by `synth_render --patch`.
- `clip` (optional): the patch's sequence as MIDI notes, played instead of the audition phrase by
  `synth_render --patch` and loaded into the web page's sequencer with the preset:
  `{ "bpm": 60, "length": 128, "loop": true, "grid": "1/4", "key": "F lydian",
     "notes": [ { "pitch": 41, "start": 0, "length": 128, "velocity": 90 }, … ] }` — pitch MIDI (60 = C4), start
  and length in beats, velocity 1..127 (default 100), length the clip and its loop, at most 256 notes; grid and key
  are the piano roll's. The boards still play the `audition` phrase.
  - `step`: beats per step (0.25 = sixteenth), `gate`: fraction of the step the note is held.
  - Notes: space-separated steps. `C3`, `Eb2`, `F#4` (C4 = MIDI 60); chord `C3+E3+G3`;
    `-` rest; `_` tie (extends the previous step); suffix `!` accent (vel 127), `?` soft (vel 50),
    `~` slide into the next note (overlap -> legato glide on mono/legato voices), per note in chords;
    `|` is ignored (bar separator for readability).

Render: `./build-host/host/synth_render --patch patches/va_acid_bass.json --out build-host/renders/x.wav`
(`--notes "..."` overrides the phrase, `--tail 1.5` adds release time).

## Song — `songs/<name>.json`

```json
{
  "version": 2, "name": "drift", "bpm": 60, "length_beats": 96, "tail_s": 10,
  "tracks": [
    { "patch": "patches/va_saw_pad.json", "notes": "D3+A3 _ _ _", "step": 4, "repeat": 2,
      "start_step": 0, "gain_db": 0, "pan": 0, "reverb_send": 0.5, "velocity": 100, "gate": 1,
      "params": { "filter": { "cutoff": 1200 } } }
  ],
  "reverb": { "decay": 0.88, "damping_hz": 4500, "predelay_s": 0.05, "size": 1.8, "return_db": -2 },
  "master": { "fade_in_s": 6, "fade_out_s": 10 }
}
```

- A track may use a **step grid** instead of `notes` (drum machines, riffs):
  `"pattern": {"kick": "X...x...X...x...", "clap": "....x.......x...", "repeat": 4}` or a list of such
  sections. Row names: drum instruments (`kick snare clap rim chat ohat ltom mtom htom cymbal cowbell
  clave`) or note names (`"C3"`). Cells: `x` hit, `X` accent, `o` ghost, `.` rest; spaces and `|` ignored.
  The step defaults to a sixteenth (`"step": 0.25`).
- `swing` 0..0.5 delays every odd step (shuffle); `humanize_velocity`, `humanize_ms` add reproducible
  looseness; `pump` `{"depth_db": 9, "release_s": 0.2, "every_beats": 1}` ducks the track on every beat
  (sidechain-style pumping).
- Notes inside a chord can carry their own accent: `C2!+F#2?`.
- `patch` is a patch file, or an **inline patch** object in the same format (a self-contained song, as the web
  sequencer exports).
- Each track is rendered alone (one engine instance, 8 voices), then mixed. `params` overrides the
  patch's settings for this track, grouped by module like a patch's. `start_step` delays the track (in steps of that track), `repeat` loops the phrase.
- One shared Dattorro plate reverb (`dsp/fx/reverb`): `decay` 0..0.99, `damping_hz` (lower = darker),
  `predelay_s` ≤ 0.25, `size` 0.5..2.
- The mix is normalized to -1 dBFS peak (the applied gain is reported).

Render: `./build-host/host/synth_render --song songs/drift.json --out build-host/renders/song_drift.wav`

## Modulation, parts and tempo in a patch

Every engine accepts the shared modules of `docs/catalog.md`:

- **modulation** (per part): `macro1`..`macro8` (`value` 0..1, `cc`); part LFOs `mlfo1`, `mlfo2` (`rate`,
  `sync` "1/8d"..., `waveform`, `retrigger`); MSEGs `mseg1`, `mseg2` (`mode` oneshot, loop_held, loop_free;
  `sync` seconds, beats; `points`, `sustain`, `loop_start`, `loop_end`; and per point `point1`.. with `time` from
  the previous point, `level` 0..1, `curve` -1..1); routes `route1`..`route8` (`source`: macro1.., mlfo1, mseg1,
  mod_wheel, aftertouch, pitch_bend, velocity, note, random; `destination`: **a parameter's role** that moves
  live, the engine's or an effect's, `fx.delay.mix`, `output.filter.cutoff`...; `amount` -1..1, a fraction of
  the destination's whole range; `via`, an optional scaling source).
- **tempo**: `tempo` (`bpm`, `clock` internal, midi); the delay's `fx.delay.sync` ("1/8d"...).
- **part**: `part` (`level`, `pan`, `channel`, `key_low`, `key_high`, `transpose`, `fx_send`, `mpe`, `mpe_bend`).

```json
"filter": {"cutoff": 900},
"mlfo1": {"sync": "1/8"},
"route1": {"source": "mlfo1", "destination": "filter.cutoff", "amount": 0.25},
"route2": {"source": "macro1", "destination": "filter.resonance", "amount": 0.5}
```
- **per-voice modulation**: `vmseg` (as `mseg1`), `vlfo` (`rate`, `sync`, `waveform`), `vroute1`..`vroute4`
  (`source`: vmseg, vlfo, velocity, note, random, pressure, slide; `destination`: pitch, level, pan, brightness,
  timbre; `amount`).
- **tuning** (global): `tuning` (`scale`, `root`, `a4`, and `degree0`..`degree11` with their `offset` in cents,
  custom).

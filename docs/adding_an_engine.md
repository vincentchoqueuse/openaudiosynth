# Adding an engine

`dsp/engines/sampler.c` is the smallest complete engine: start from it.

1. **Header `dsp/engines/<name>.h`**: parameter enum (`<NAME>_P_...`, `<NAME>_P_COUNT`), `extern const
   param_desc_t <name>_params[]`, `extern const engine_ops_t <name>_engine`, the per-voice struct and
   the engine struct (which contains a `vpoly_t poly` and the voice array).
2. **Descriptor table** with `PARAM(ID, "name", min, max, default, curve, "unit", modulatable, labels,
   "help")`. Physical units; `help` says what the parameter does *to the sound* (agents read it).
   Append new parameters at the end of an existing table so ids and presets stay valid.
3. **vpoly callbacks**: `start(eng, v, note, vel, hard)` (hard = reset the voice state),
   `release`, `level` (for stealing), `silence` (after a steal fade).
4. **`engine_ops_t`**: `init` (all parameters at default), `poly`, `set_param` (normalized → physical
   with `param_from_norm`), `pitch_bend`, optional `mod_wheel` / `cc`, `render` (adds one
   `SYNTH_BLOCK`; per voice: render into a mono block, then `voice_out(...)` (steal fade, NaN guard,
   pan into L/R) and `vpoly_end_block`). Shared helpers in `dsp/voice/voice.h`: `voice_pan`,
   `voice_glide_coef`, `dsp_ramp_env_mul`, `voice_out`; on/off switches use `param_onoff_labels`.
5. **Register**: add `SYNTH_ENGINE_<NAME>` before `SYNTH_ENGINE_COUNT` in `dsp/synth.h`, the state to
   the union in `dsp/engines/registry.h`, the ops to `dsp/engines/registry.c`, the source to
   `CMakeLists.txt`.
6. **Test** (`tests/test_<name>.c` defining `suite_<name>()`, plus one `TEST_SUITE(<name>)` line in
   `tests/suites.h`; ctest picks it up): no NaN / bounded under random parameters and notes, bit-exact determinism, expected
   response (pitch, decay times...).
7. The catalog (`docs/catalog.md`, `docs/catalog.json`) is regenerated by the build (`just build`); add
   recipes to `docs/sound_design.md`, a few `patches/`, a bench line in `tests/bench.c`.

8. **Check**: `ctest` runs `rules` (`tools/check_rules.py`: portable `dsp/`, no libm/allocation/I/O,
   headers, the engine is registered, built, tested and has a patch) and `golden` (`tools/golden.py`:
   every patch and song keeps its audio hash; new patches are reported as "new" until
   `tools/golden.py --render build-host/host/synth_render --update` records them).

Real-time rules (CLAUDE.md): no allocation, no libm per sample (use `core/fastmath.h`), no division in
inner loops, everything that touches gain/pitch/cutoff interpolated over the block.

Stage ids share one namespace with the effect bus in the interfaces' chain diagram: do not name an engine stage
`delay`, `reverb`, `chorus`, `phaser`, `flanger`, `crush`, `master`, `saturation` or `limiter` (an engine with a delay of its own gives its stage another id, such as `comb`).
